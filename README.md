# AQA Automation Student Template

Минимальная заготовка для вашей собственной автоматизации на Python. Здесь есть один health check: он проверяет доступность учебного приложения. Остальные тесты и архитектуру вы создаёте самостоятельно.

До ручного слияния подготовительного PR ветка по умолчанию — `template/v1`.

## Подготовка

1. Создайте свой репозиторий кнопкой **Use this template** на GitHub, затем клонируйте его и откройте его каталог в терминале.
2. Установите [uv по официальной инструкции](https://docs.astral.sh/uv/getting-started/installation/).
3. Установите зависимости проекта:

```bash
uv sync --locked
```

Используется Python 3.13; uv при необходимости установит его. Файл `uv.lock` фиксирует зависимости для повторяемой установки.

## Запуск приложения и теста

Учебное приложение находится в отдельном репозитории [aqa-training-sut](https://github.com/val1n2501-glitch/aqa-training-sut). Откройте для него отдельный терминал и выполните:

```bash
git clone https://github.com/val1n2501-glitch/aqa-training-sut.git
cd aqa-training-sut
uv sync --locked
uv run --locked python -m app
```

Оставьте приложение работающим. В терминале своего репозитория запустите:

```bash
uv run --locked pytest
```

По умолчанию тест обращается к `http://127.0.0.1:8000/api/health`. Таймаут запроса — 5 секунд. Если соединение не установлено, проверьте, что приложение запущено, а адрес и порт верны.

Для другого адреса задайте `BASE_URL` перед запуском теста.

Bash / zsh:

```bash
export BASE_URL="http://127.0.0.1:8000"
uv run --locked pytest
```

PowerShell:

```powershell
$env:BASE_URL = "http://127.0.0.1:8000"
uv run --locked pytest
```

`.env.example` показывает имя переменной и пример значения. Файл `.env` автоматически не загружается: задавайте переменную в терминале, как показано выше.

## Структура

```text
tests/
├── api/
│   └── test_health.py
├── ui/
│   └── .gitkeep
└── conftest.py
.env.example
pyproject.toml
uv.lock
```

`conftest.py` пустой, каталог `ui` подготовлен для будущих тестов.

## Место в курсе

- **Course Site** — уроки, задания и прогресс.
- **ChatGPT Project** — персональный наставник.
- **SUT** — приложение под тестирование.
- **Student repository** — ваша собственная автоматизация.
